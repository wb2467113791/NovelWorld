# V4：3–5 分钟演示

这是人工在线演示指南，不属于自动测试，也不是预写 NPC 剧情。在线启动与 NPC/Chroma 可能调用配置的付费模型；没有密钥时直接使用 README 的离线 Eval，不执行本指南。无需增加 live-model 脚本或更换模型。

## 准备

按 README 启动 MySQL、Java、Python。启动 Python 前设置 `NOVELWORLD_DIRECTOR=off`，使用配置好的 DASHSCOPE_API_KEY。所有浏览器操作走 Java 8080。

暂停当前世界，在开局工坊读取默认模板，创建专用的新演示世界。增加 `player: {"name": "旅人", "location": "晚风客栈"}`，让玩家与苏晚同地点，其他默认 NPC、对象和目标保留。Java 校验并新建世界 ID，不改已有世界。预先完成索引初始化以避免录制时等待；初始化可能收费。Observe 先确认登记簿和钥匙在客栈。

## A：自主世界（约 1 分钟）

Observe 中推进 10–20 Tick，期间不输入和投放线索。指出 bootstrap 后由 Event、Conversation、Agenda 继续提供机会，Director 已关闭。时间线行动必须有 Java Event；如果模型选择等待，也展示下一自主提醒。无需要求 NPC 必须移动到某地点或调查某对象。

## B：玩家交流（约 1 分钟）

暂停批量运行，切换 Play，向附近苏晚发送“你好，我想了解客栈”。成功行动只推进玩家自己的 Tick。点击下一 Tick，NPC 在真实会话轮次中自主决定回应；Play 显示当前会话和等待谁输入。回复文字或措辞不固定，若 NPC 选择结束也如实展示，不强迫续聊。

## C：错误信息（约 1 分钟）

玩家说“钥匙在县衙”。在 Play 时间线展示真实消息；切回 Observe 查看钥匙仍在客栈。Belief 的来源/未验证分区可通过角色 Prompt 代码和离线 Eval 输出说明，当前 UI 没有单独 Belief 编辑/展示面板，不伪装成 UI 已实现。该说法不进入 verified semantic，也不自动被判为谎言。

## D：同一世界规则（约 1 分钟）

Play 查看一个当前可见、可携带对象，拿取后交给苏晚。展示 inventory、持有者和真实 give Event；Observe 查看苏晚对旅人的简化关系增加 2，以及 NPC 的行为 Memory。若对象被 NPC 先拿走，选择另一个仍可见对象，不要求模型配合。

可以故意重复交付已经交出的对象：Java 拒绝，不再加关系，不产生第二个成功事件。玩家不拥有直接改关系的按钮。

## 录制时的边界

演示证明行动闭环与信息边界，不证明“剧情自然度”。提前说明启动服务、模型延迟和向量费用。出现世界运行冲突时先暂停；旧页面切换世界后重新读状态；已提交 warning 不重发行动。空状态或服务错误有页面提示，不通过删除存档解决。

想要完全可重复的证据，展示 `python -m eval.long_run --ticks 1000 --boundaries` 结果，它使用 scripted decisions、生产 Java 规则和临时 H2，不连接现有世界或商业模型。
