# 3–5分钟演示

先按README启动三个进程：数据库与缓存、Spring Boot、Python Runtime。不要用旧世界展示新格式。

1. 打开上帝视角。介绍四个人的身份、私人想法和不同地点，说明没有预写的结局。
2. 单步走过5分钟。观察谁开始工作、谁发起交谈，并点击人物查看动机和个人计划。
3. 运行一小时。看活动持续与完成、邀请接受或拒绝、连续交流及之后的安排。没有交流时如实说明模型选择，不把人工脚本当成自主行为。
4. 点击同一人物的手记：对照亲历、听到的说法、关系印象与引用经历形成的反思。
5. 不必切换页面或暂停，展开“走进小镇”，以旅人身份向现场的人发出邀请。等待当前轮次结束后行动结算，后续NPC自主回应。参与面板只提供现场可见信息，旁观区的纪事与人物手记继续保留；可以收起面板继续观察。
6. 暂停并重启Python，展示当前时间、活动、会话和记忆恢复。MySQL是权威存档，Python只保留世界ID。

## 验收边界

构建与离线闭环检查使用确定性的决策替身，覆盖持续活动、会话轮次、信息隔离和保存恢复，不请求付费模型。它们证明程序规则，不证明模型叙事质量。

真实模型观察重点：是否持续有角色行动、是否回应对方内容、是否因新经历调整安排、是否反复重复、是否虚构不存在的效果。真实试跑前应明确轮次上限，控制生成与向量接口调用。

本次重构撤下旧版大量回归测试，因为其业务语义已删除；不增加一套庞大测试。实际验证结果以本次交付报告为准，不沿用旧版“1000 Tick通过”等数字。
