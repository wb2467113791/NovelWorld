# 青石镇的普通一天

默认开局内容改为三个普通人的小镇生活。没有共同主线、指定反派、谜底或必须执行的任务；第 10/30 Tick 的剧情由角色决策和实际世界行动产生。这里只更换统一模板 JSON、Director fallback 文字及相关断言，没有改变任何规则、调度、Skill、接口或存档格式。

## 人物与信息

| NPC | 长期动机 | 私人压力 | 本人初始知道 |
|---|---|---|---|
| 林默 | 做好日常差事、建立可靠声誉、兼顾规矩与人情 | 在意上司认可，担心灵活处理被视为不可靠 | 商会征集下周集市意见；苏晚曾无条件给当值捕快留热茶 |
| 苏晚 | 稳定经营、维持各类关系、保有私人空间 | 资金周转紧，不愿告诉熟客，未决定求助 | 商会问过包桌但未约定；常住熟客不喜欢一楼拥挤 |
| 赵无极 | 扩大影响、维持体面地位、互利合作、避免公开争执 | 最近交易收益不如预期，担心判断失准被人议论 | 县衙希望主动登记外来货物；苏晚合作过聚餐但坚持自主安排 |

起点仍是林默在县衙、苏晚在晚风客栈、赵无极在青石街，08:00。初始关系：林默→苏晚 +5、→赵无极 0；苏晚→林默 0、→赵无极 −5；赵无极→林默 +5、→苏晚 +10。关系历史有善意与小分歧，没有规定敌对阵营。Secrets 不放入 public Lore，仍走原有角色知识边界。

## 五处潜在张力

- 包桌可能带来收入，也可能挤占熟客的安静空间；商会影响力与老板自主经营之间有协商余地。
- 苏晚的周转压力可能促成合作或让她更谨慎；是否开口、找谁谈都未规定。
- 林默想建立信任，捕快身份与重规矩的习惯可能让别人谨慎，也可能提供可靠感。
- 商会希望办事便利，县衙希望日常登记有序；双方可以沟通，也可能对介入程度理解不同。
- 无日期便笺、空白摊位和备用钥匙可能被注意、忽略、误解或交付；不承担任务道具职责。

## 对象与设定

12 个 canonical 对象：客栈的住客登记簿、后门、木箱、钥匙（备用）、遗落便笺；青石街的商会公告、摊位登记单；县衙的值班记录、公告板；林默持有捕快腰牌、苏晚持有私人账本、赵无极持有商会令牌。

木箱仍是一层固定容器，后门仅 open/close，其余没有新增能力。部分纸本可携带，公告固定；备用钥匙未新增开锁规则。对象以现有 stable ID 规则创建，保留沿用对象的 ID。人物 items 仍不作为模板输入 authority。简短公开 Lore 只介绍地理、客栈、商会、县衙日常职责和集市习惯。

三人的默认 Goal 不要求调查/隐瞒，因此不加载现有 investigation/concealment 指导是正常结果。没有为了演示 Skill 强塞目标，也没有改变 Router。

Director 仅替换三段 fallback：stagnation 为未署名集市便笺，participation 为临时寄放货物的议论，conflict 为商户与县衙对集市空间安排的不同说法。类别、冷却、触发条件、模型请求和调度全部保持原样。
