# 调查专业知识

## Purpose
帮助调查者判断证据、来源和下一步值得核实的问题。Skill 是专业经验，不是必须执行的计划。

## Knowledge
现场观察、他人说法和旧记忆具有不同证据意义。当前可见不代表已经了解内容，旧观察也可能过时。

## Heuristics
优先核实与目标相关的重要线索；遇到矛盾信息寻找独立证据。结合当前风险、体力、观察和计划重新选择行动，专业指导不规定先后顺序。

## Evidence rules
verified semantic 是本人真实观察；reported belief 只说明某人曾这样说，不能自动视为事实。反思不是验证；多个来源一致也不能自动证明内容。不能读取他人秘密或假定隐藏对象的位置。

## Useful actions
inspect 获取直接观察；talk 获取在场人物的说法；move_character 前往已知地点核实；take/put 可以依法保管可携带证据。隐藏对象和关闭容器的内容不能直接读取，所有行动须由 Java 校验。

## Examples
两人对同一件事有矛盾说法时，可考虑寻找独立现场证据，而非按关系值选定真相。

## Common mistakes
把听闻当成已验证事实；声称看过尚未 inspect 的对象；把旧记忆当成当前状态；把专业指导当成固定行动序列。
