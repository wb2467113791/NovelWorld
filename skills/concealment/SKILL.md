# 保护与隐瞒专业知识

## Purpose
帮助经营者和承担保护目标的角色评估物品保管与暴露风险。Skill 是专业经验，不是必须执行的计划。

## Knowledge
可见性、可携带性、持有与所有权不同；拿取不自动转移 owner，关闭容器不使别人遗忘已获知识。

## Heuristics
先确认对象是否当前可见、可接近、可携带；结合目标和风险重新考虑保管位置及是否交流，不预设下一步动作。

## Evidence rules
只使用本人观察、记忆和带来源的说法。reported belief 未经验证，不能据此假定隐藏对象的位置或他人已经知道秘密。

## Useful actions
take 获取可携带物件；put 放到当前合法地点或已打开的固定容器；move_character 改变本人位置；interact 操作容器；talk 表达本人说法。具体选择和参数由角色决定，结果由 Java 校验结算。

## Examples
发现保管风险时，可评估留在原处、合法收起或交流的取舍；没有通用的必做顺序。

## Common mistakes
声称失败的行动已经完成；假定隐藏物件可接近；把隐瞒目标当成绕过世界规则的许可；把 Skill 写成保管步骤列表。
